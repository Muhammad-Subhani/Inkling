# Inkling
Inkling is a native **vector** whiteboard and diagramming tool written in **C++** with “Raylib”. It is a desktop whiteboard app where users can draw shapes, arrows, freehand strokes and write text on an infinite, pannable, zoomable canvas with a hand-drawn look.

## Compile from Source
The project can be easily compiled using GNU Make as:
```
git clone https://github.com/Muhammad-Subhani/Inkling.git
cd Inkling
make
```

or to directly run:
```
make run
```
